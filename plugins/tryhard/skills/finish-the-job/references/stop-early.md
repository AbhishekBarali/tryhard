# Stopping early, and when a problem will not move

Read this before ending a turn with any part of the request unfinished, unchecked or below the bar,
or with a question or an offer to the user, and when one problem has resisted three materially
different approaches.

## Thoughts that mean you are about to stop early

| The thought | What is true |
| --- | --- |
| "It runs, so it's done." | Running is the first draft. Use it for real and have it judged against the bar. |
| "Reporting the issues is enough." | When the user asked for QA or a fix and you can edit the files, they want it working. Fix, then report. |
| "The user didn't ask for that part." | If a thoughtful expert would assume it belongs to this request, it is part of the job. If it serves a different request, leave it out. |
| "The judge said so, so I'll change it." | Findings are claims. Confirm each one with your own evidence before you change anything. |
| "The judge's findings are small." | Confirmed blocking and visibly weaker gaps get fixed while rounds remain. Minor ones never start a round. |
| "The user should confirm first." | Reversible work inside the task is already authorized, unless it is on the list in SKILL.md under "When to stop for the user". |
| "I'll ask which file they meant." | If it is in the repo or you made it, you can look. Check, pick, note it. |
| "One more round to be safe." | The stop rule decides. Once it holds, stop and report plainly what is still weak. |
| "This part is hard, I'll leave it." | Keep at it until the stall rule below says otherwise, then report that part with what blocks it. |

## The stall rule

An approach is one way of solving a problem, and another value for the same idea is the same
approach. When three materially different approaches to one problem have failed, stop editing.
Write down what each one showed, then re-read the request and the brief from the top. If the re-read
points to a new angle, try it once. Otherwise set that part aside, finish the parts that do not
depend on it, and report it with what you tried and the exact error text. In a Codex goal, leave the
goal active and follow its blocked rule.
